Load your own data (admin)

Drop CSV files here, or click to choose them
Each file needs a student_id column. Add as many files as you have (academic, attendance, LMS...).
Which columns can I use?
  • Academic: cgpa, backlogs, plus optional name, department, semester
  • Attendance: overall_pct
  • LMS: logins_per_week, assignment_completion_pct
  • Engagement: events, clubs, hackathons, certifications
  • Placement: aptitude, coding, mock_interview, technical_skill (Beginner/Intermediate/Advanced), soft_skill_score
  • Psychometrics (0-100 scales): conscientiousness, openness, extraversion, agreeableness, emotional_stability, grit, motivation, stress_level
  • Survey file (needs a wave column): student_id, wave, seconds, w1-w5, p1-p4, u1-u3, q1-q2, g1-g2, b1-b3, e1-e3, s1-s2, sh, ref. Weekly file (needs a week column): student_id, week, attendance_pct, logins
  • Events file (needs title and host columns): title, type, host, date (YYYY-MM-DD), mode, location, deadline, link, skills (a;b), team_size, prize, description
  • Faculty availability file (needs faculty, start, end): faculty, department, role, room, day (Mon-Sat), start (HH:MM), end (HH:MM), one row per free slot
  • Feedback: satisfaction, faculty_feedback (1 to 5)
Any column you don't have is skipped and the remaining weights are rescaled. Files can be split any way you like; they are joined on student_id.

Score settings (weights and risk cut-offs)

Weights are rescaled to 100%. Change them and everything below updates instantly.
